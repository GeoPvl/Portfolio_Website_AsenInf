# Задание за Стажантска Програма INFORCE: "Моето интерактивно портфолио"
**Кандидат:** Георги  
**Направление:** Програмиране  

## 1. Общ преглед и Инструкции за стартиране
Проектът представлява уебсайт за лично представяне на Георги и интерактивно проследяване на учебни цели (Learning Goal Tracker). Разработен е стриктно според изискваните критерии на INFORCE, като използва чист **HTML5**, **CSS3** и **Vanilla JavaScript (ES6)** без никакви външни библиотеки, рамки или емотикони.

### Как да стартирате сайта:
1. Отворете файла `index.html` в браузър по ваш избор (Chrome, Firefox, Edge, Safari).
2. Не се изисква локален сървър или инсталация на допълнителни зависимости.
